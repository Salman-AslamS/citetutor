# CiteTutor

A citation-first RAG tutor for course textbooks, with a built-in evaluation harness.

## The problem

Students who ask an AI about their course material get fluent answers with no way to check them, and the AI will happily make things up when the textbook does not cover the question. CiteTutor answers questions from an open-licensed textbook (OpenStax Introductory Statistics), cites the exact chapter and page for every claim, and says so plainly when the material does not cover the question. What sets it apart is that it is measured: a hand-written golden test set, retrieval and faithfulness metrics, and an ablation table showing what each component contributes.
